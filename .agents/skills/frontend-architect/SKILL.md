# Frontend architect

Before any UI work:

1. Read `/DESIGN.md` and `/CLAUDE.md`.
2. Read `.agents/skills/impeccable/SKILL.md` for anti-slop audit/polish.
3. Read `.agents/skills/design-taste-frontend/SKILL.md` for bold/motion/density.
4. Read `.agents/skills/web-design-guidelines/SKILL.md` for UX and a11y.

Then implement. After visual changes, verify in the browser: click the flow,
screenshot, fix overflow/overlap, then finish.
